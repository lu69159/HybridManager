# 内容混合管理器：管理星球上的模组内容

**像素工厂V8版本更改了星球机制，不同星球的内容默认不可见。此模组旨在让玩家能够修改每个星球上的显示内容。**

- 你仍然需要解锁对应科技才能在星球上使用添加的内容

- 此模组内容正在移植到MoreCustomSettings，如果与MoreCustomSettings一起使用，请关闭MoreCustomSettings设置中的***启用自定义内容管理***

***
# Contents Hybrid Manager: A mod that manage mod content

**In Mindustry V8, the planet mechanics have been changed; content from different planets is hidden by default. This mod is designed to allow players to customize what is displayed on each planet.**

- You still need to unlock the relevant tech in order to use the added content on the planet.


- This mod's content is being ported to MoreCustomSettings. If used together with MoreCustomSettings mod, please disable ***Enable Custom Content Manager*** in the MoreCustomSettings settings."
