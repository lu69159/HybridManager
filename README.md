# Contents Hybrid Manager: A mod that manage mod content

**In Mindustry V8, the planet mechanics have been changed; content from different planets is hidden by default. This mod is designed to allow players to customize what is displayed on each planet.**

- You still need to unlock the relevant tech in order to use the added content on the planet.
